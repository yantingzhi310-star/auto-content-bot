# TOP5 选题推荐

## 选题1：你家可能囤着致癌日用品
形式：实物盘点+字幕解说（不露脸，只出手/桌面俯拍）
脚本框架：
1. 开头钩子：镜头扫过家里常见日用品（洗衣液/塑料饭盒/香薰/不粘锅），字幕「这4样东西，可能正在慢慢伤害你」
2. 逐条点名：每样一个特写+来源依据（引用热搜/检测报告口播）
3. 反转：不是让你扔，是教你「怎么挑才对」——给出3条购买避坑口诀
4. 结尾：评论区互动「你家有几样？」引导晒图
优势：健康焦虑+实用，天然高完播、高收藏。

## 选题2：休息日5小时没回消息老师申请仲裁
形式：聊天记录截图+配音解说（纯屏幕录制）
脚本框架：
1. 开头：模拟对话界面打出「休息日，领导消息5小时没回，然后…」，钩子留悬
2. 还原事件：时间线梳理（截图/文字动画），点出「仲裁结果」
3. 法律科普：休息日回复消息算不算加班？3句话说清
4. 结尾站队提问：「换你会回吗？」引战评论区
优势：职场共鸣极强，纯截图+配音零出镜，易爆。

## 选题3：微信转账加一个动作
形式：手机录屏实操演示（只录屏幕+手部操作）
脚本框架：
1. 开头：直接录屏转账界面，「转账前加这一步，能救你一大笔钱」
2. 演示：设置转账到账时间/备注用途/延时到账防诈骗，一步步点
3. 场景化：遇上骗子/转错账时，这一步怎么帮你追回
4. 结尾：「转发给爸妈」，引导分享
优势：工具类强需求，录屏即可，转发率高。

## 选题4：海淀鸡娃父母终于承认天赋重要
形式：观点解说+素材画面（新闻/数据图表配音）
脚本框架：
1. 开头抛争议：「卷了十几年的海淀家长，居然认输了？」
2. 呈现现象：采访/数据/案例，说明「天赋论」为何抬头
3. 双向拆解：努力还有没有用？给出「努力决定下限、天赋决定上限」的平衡观点
4. 结尾金句收尾+提问「你信天赋还是信努力？」
优势：教育话题常青，观点类不露脸最好做。

## 选题5：中国女生借卫生巾震撼外国网友
形式：跨文化盘点+配音画面（外网评论截图/搬运素材）
脚本框架：
1. 开头：「一件小事，让外国网友破防了」
2. 讲事件：中国女生随手借卫生巾的互助文化，对比国外「卫生巾贫困」现状
3. 升华：小物件背后是女性互助与社会温度
4. 结尾互动：「你被陌生人帮过吗？」
优势：温情+文化差异，素材现成，配音即可。

# 优选完整脚本

**选题：微信转账加一个动作（选题3）**
理由：工具类刚需、录屏零出镜、转发率最高、制作成本最低，当天可出片。

| 时间 | 画面 | 台词 |
|---|---|---|
| 0-3s | 手机录屏，转账输入金额界面，手指悬停在「转账」按钮上 | 转账前，先别急着点确认！加一个动作，关键时刻能救你一笔钱。 |
| 3-10s | 点击金额下方「添加转账说明」，弹出输入框 | 第一步，点这里，写上转账用途，比如「借款」「货款」「房租」。 |
| 10-18s | 特写备注文字，画面打红框强调 | 别小看这几个字，一旦有纠纷，它就是最直接的证据，法院都认。 |
| 18-28s | 返回，点右上角「···」，找到「转账到账时间」 | 第二步，把到账时间改成「2小时到账」或「24小时到账」。 |
| 28-38s | 演示设置成功界面，配诈骗场景动画小图标 | 转错了、遇上骗子了，这段时间就是你追回钱的黄金窗口。 |
| 38-48s | 分屏：左「实时到账」右「延时到账」，对比打叉打勾 | 实时到账，钱一出去就难追；延时到账，给自己留条后路。 |
| 48-56s | 录屏回到转账页，手指流畅操作一遍完整流程 | 备注写清楚，到账设延时，两步，一分钟，学会了吗？ |
| 56-60s | 黑底白字大字：「转发给爸妈」+ 箭头指向分享按钮 | 赶紧转发给家里人，尤其是爸妈，别让他们吃亏。 |
