# TOP5 选题推荐

## 选题1：考上北大第二天就复读？全家100个反对，他到底图什么
形式：解说 + 聊天记录/新闻截图/校园空镜混剪
脚本框架：
1. 钩子：考上北大，第二天说“我要复读”——全网都懵了
2. 还原事件：分数/专业/家庭反应，全家100个反对
3. 三种猜测：专业不满意？清北情结？还是流量炒作？
4. 反转视角：如果他是你孩子，你支持吗？
5. 结尾提问：换你，北大和“再来一次”选哪个？

## 选题2：海姆立克急救法变了！旧方法可能救不了人
形式：动画演示 + 字幕解说（不露脸）
脚本框架：
1. 钩子：你学的海姆立克，可能已经是“旧版”
2. 新旧对比：按压位置/力度/顺序变化
3. 常见误区：拍背、抠喉、倒挂
4. 正确步骤：成人/儿童/婴儿三版拆解
5. 结尾：收藏转发，关键时候能救命

## 选题3：脑出血自救要点，40岁后必须知道
形式：黑底白字 + 心电图/医院走廊空镜 + 配音
脚本框架：
1. 钩子：脑出血不是“突然”，身体给过你信号
2. 3个预警：剧烈头痛、单侧无力、说话含糊
3. 自救4步：打120、侧卧、别乱吃药、记录时间
4. 高危人群：高血压、熬夜、情绪激动
5. 结尾：转发给家里那个“倔老头”

## 选题4：敬一丹去世刷屏，倪萍哭到发抖——我们怀念的到底是什么
形式：老照片轮播 + 新闻播报原声 + 旁白解说
脚本框架：
1. 钩子：今天的微博，一半在哭敬一丹
2. 她是谁：焦点访谈、感动中国、一代人的新闻记忆
3. 倪萍的反应：哭到浑身发抖，老一辈的情谊
4. 为什么刷屏：不是流量，是集体记忆的告别
5. 结尾：那个“说人话”的新闻时代，走远了

## 选题5：刀郎音乐会一首没唱，为什么全网反而更买账
形式：现场画面混剪 + 乐评解说
脚本框架：
1. 钩子：买票听刀郎，结果他一首没唱
2. 现场还原：说了什么、做了什么、观众什么反应
3. 对比视角：别的歌手假唱/划水，他“不唱”反而封神
4. 刀郎的逻辑：音乐之外，他想说的更重要
5. 结尾：真正的顶流，不需要开口
