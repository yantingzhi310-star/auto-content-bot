# TOP5 选题推荐

## 选题1：今起公积金提取场景6变9，你的钱更好拿了
形式：录屏解说 + 政策对比图
脚本框架：
1. 开头3秒：直接甩“公积金提取从6种变9种，多出来的3种跟你直接相关”
2. 中间：逐条列出新增的3种提取场景（画面用手机录屏+大字标注）
3. 举例：什么情况下能提、能提多少、去哪办
4. 结尾：提醒“别急着提，先看自己符不符合”，引导评论区问“你所在城市执行了吗”

## 选题2：秦始皇陵为什么不挖？不是不敢，是挖了收不了场
形式：历史解说 + 文物/地宫画面素材
脚本框架：
1. 开头：抛悬念“秦始皇陵不是找不到，是找到了也不敢动”
2. 列3个核心原因：水银污染、文物保护技术不够、开挖等于破坏
3. 用“兵马俑褪色”做案例对比
4. 结尾：反问“你觉得有生之年能看到地宫打开吗”，引导互动

## 选题3：日本人平均身高被中韩超越，背后原因很现实
形式：数据盘点 + 图表动画
脚本框架：
1. 开头：甩数据“日本男性平均身高被中韩反超，不是偶然”
2. 三个原因：饮食结构变化、基因天花板、社会压力影响发育
3. 对比中韩近30年身高增长曲线
4. 结尾：不评价，只陈述，引导“你怎么看”

## 选题4：长期不工作的人会失去什么？不是钱，是这3样
形式：配音画面 + 情绪向剪辑
脚本框架：
1. 开头：用一句扎心话切入“不上班最可怕的不是没钱”
2. 三点递进：失去社交节奏、失去时间感知、失去自我评价体系
3. 每点配一个真实感强的场景画面（空房间、白天睡觉、刷手机）
4. 结尾：不是劝你上班，是劝你别丢掉“结构感”

## 选题5：调休“假装大方”，到底谁在占谁便宜
形式：吐槽解说 + 日历/调休对比图
脚本框架：
1. 开头：直接开怼“调休就是把你自己的周末还给你，还让你感恩”
2. 用日历图展示“放3天实际只放1天”的逻辑
3. 对比不同国家的休假制度（点到为止）
4. 结尾：不说结论，问“你支持取消调休吗”
