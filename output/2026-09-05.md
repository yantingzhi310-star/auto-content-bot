# TOP5 选题推荐

## 选题1：我好像突然对钱有了概念
形式：第一人称经历独白 + 白底黑字/插画/生活空镜（如外卖、工资条、超市价签）
脚本框架：
- 钩子(0-5s)：抛出一个荒诞对比，“小时候觉得500块是巨款，现在打开支付软件500块根本不经花”。
- 展开(5-40s)：列出3-4个具体“对钱有了概念”的瞬间（房租=一个月通勤? 看病一次=一个包? 加班时薪买不起一杯奶茶?），每个瞬间配一个静态画面或简笔动画。
- 对比(40-50s)：把“理想中的花钱”与“现实中的花钱”用同屏文字/图片反差呈现。
- 结尾(50-60s)：留一句共鸣金句，引导用户评论区晒自己“突然懂钱”的瞬间。
可做性：生活共鸣极强，不需要任何真实人物出镜，拍摄成本极低，用手机备忘录或字幕动画即可完成。

## 选题2：氯雷他定和西替利嗪选哪个好
形式：医学冷知识解说 + 分屏对比图 + 药盒/成分表实拍（避免露手）
脚本框架：
- 钩子：“同样是抗过敏药，氯雷他定和西替利嗪差一个字，副作用天差地别”。
- 对比讲解(5-35s)：用图表展示起效时间、嗜睡程度、适用年龄/人群（孕妇/儿童）。
- 场景化建议(35-50s)：过敏季节+开车党选谁？有娃家庭选谁？晚上痒得睡不着选谁？
- 结尾(50-60s)：给一个自测清单，引导评论区留言自己症状求推荐。
可做性：高需求、高搜索、长尾。全程只需药品说明书截图+文字标注，无需真实人物。

## 选题3：花少2 母带 与 极限挑战六人重聚为何争议重重（合并做盘点）
形式：综艺考古解说 + 经典冲突片段截取（无正脸亦可）+ 字幕大字报/时间轴
脚本框架：
- 钩子：“7年前的真人秀母带，为什么到现在还能让内娱翻天？”。
- 背景(5-25s)：简述花少2的历史名场面，再闪切极挑男人帮变故，引出“综艺剧本与真性情”的争论。
- 对比盘点(25-50s)：平行剪辑两个节目中的争议瞬间，配合犀利点评文案（如“真人秀最怕认真的人”）。
- 结尾(50-60s)：拷问“综艺究竟该有剧本还是该真实？”，引导站队投票。
可做性：纯素材剪辑+字幕文案，片库素材丰富，零露脸，且自带巨大讨论声量。

## 选题4：汤家凤呼吁取消英语主科地位
形式：观点分析解说 + 评论区热议截屏 / 数据图表（英语使用率、投入产出比）
脚本框架：
- 钩子：“每天2小时学了16年英语，最后用到的只有ok和thank you？”。直接用汤家凤原话截取做引子。
- 现状(5-25s)：列数据：全国英语培训市场规模、学生日均英语学习时长，对比工作后英语使用率不足5%。
- 两边观点(25-45s)：左or右版截图，代表“支持取消”和“坚决反对”理由。
- 我的立场(45-55s)：不站队，给一个折中方案（如改为选修/降低分值）。
- 结尾(55-60s)：抛出问题——如果当年不学英语，你现在多出的2000小时会拿去做什么？
可做性：教育话题极度煽动情绪，讨论度天然高。只需引用公开视频+数字大字报即可。

## 选题5：江西吉安山体滑坡十余人被埋
形式：避险科普 + 灾害亲历者文字转述（无画面或避免血腥图）+ 地图/动图示意
脚本框架：
- 钩子：“又是山体滑坡，这5条自救法则能救命，希望你永远用不上。”由热搜新闻切入。
- 案例复盘(5-25s)：用文字+示意图还原“滑坡前兆”（裂缝、异常声响、浊水），结合江西现场简报。
- 逃生法则(25-50s)：逐条解说5条保命法则（横向跑、勿顺坡跑、护住头部、远离河谷、被埋后如何保存体力）。
- 结尾(50-60s)：转发提醒家人，评论区留下你所在地区的常见自然灾害。
可做性：社会热点+强实用价值。不需要任何真实灾害画面，用矢量示意图、色块+语音即可完成制作。
