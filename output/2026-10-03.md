# TOP5 选题推荐

## 选题1：高速充电80%强制离场，到底谁在耍流氓？
形式：解说 + 高速服务区实拍画面/充电桩界面录屏 + 字幕动画
脚本框架：
1. 开头抛出争议：高速充电到80%被强制要求离场，车主怒斥“我花钱凭什么赶我走”
2. 双方观点对撞：一方说“充电桩是公共资源，占着茅坑不拉屎就是自私”；另一方说“我充到100%是我的权利，80%续航根本不够跑”
3. 算一笔账：节假日充电桩排队数据+充电效率曲线科普（80%后充电速度断崖式下降）
4. 收尾抛问题：如果是你，80%被要求挪车，你走不走？评论区吵起来

## 选题2：AI面试恐怖谷——你被机器人淘汰了，连为什么都不知道
形式：录屏 + 配音解说 + 聊天记录截图/模拟AI面试界面
脚本框架：
1. 热点切入：AI面试上热搜，求职者说“对面不是人，但比人更让人窒息”
2. 盘点AI面试的“恐怖”细节：微表情分析、语音语调打分、回答超时直接淘汰
3. 真实案例：有人因为“眨眼频率异常”被标记不稳定
4. 给出生存指南：AI面试3个潜规则+2个必过话术
5. 结尾：以后面试你的不是HR，是一串代码

## 选题3：小伙入职就弄丢10台苹果手机，这锅到底谁背？
形式：解说 + 聊天记录/新闻截图 + 流程拆解动画
脚本框架：
1. 事件还原：刚毕业小伙入职第一天/第一周，10台苹果手机不翼而飞
2. 责任拆解：公司让新人单独押送贵重物品，流程有没有问题？
3. 法律视角：员工弄丢公司财物，到底要不要全额赔？劳动法怎么说
4. 打工人自保指南：入职遇到“让你单独管贵重物品”的公司，留个心眼
5. 结尾：这10台手机，可能是一个年轻人一年的工资

## 选题4：原来出餐快也不一定就是预制菜——餐饮老板不会告诉你的真相
形式：后厨实拍素材剪辑 + 解说 + 对比画面
脚本框架：
1. 打破认知：出餐快=预制菜？不一定，有些菜天生就快
2. 分类盘点：哪些菜快是正常的（炒饭、面、蒸菜），哪些菜快才可疑（红烧肉、炖汤）
3. 教你3秒判断：看菜单结构、看后厨动线、看菜品温度
4. 预制菜不可怕，可怕的是花了现炒的钱吃了料理包
5. 结尾：下次点外卖，你知道该看什么了

## 选题5：张继科杯球迷大骂发球遮挡——乒乓球圈最敏感的“灰色地带”
形式：比赛画面剪辑 + 规则动画演示 + 解说

1. 事件回顾：张继科杯比赛现场，球迷因发球遮挡爆发骂战
2. 科普：什么是发球遮挡？为什么它是乒乓球最容易被骂的规则

4. 球迷文化：为什么这个话题一点就炸
5. 结尾：规则是规则，但情绪也是真的
