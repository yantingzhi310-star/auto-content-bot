# TOP5 选题推荐

## 选题1：微信“单删提示”背后，藏着多少人的体面与心碎
**形式**：情绪配音 + 手机录屏/微信聊天记录滚动（不露脸）
**脚本框架**：
1. 痛点引入：你知道微信什么时候才提示“对方删了你”吗？
2. 场景延展：借钱被删、离职被删、前任被删（举2-3个真实感强例子）
3. 反转升华：其实单删提示早就有，只是你给的钱不够多（引出“红色感叹号”判据）
4. 情感共鸣：被删不是你的错，是TA没魄力说再见。引发评论“你被谁删过”。

## 选题2：多地中考历史不计入总分，“历史”真的没用吗？
**形式**：数据盘点 + 历史素材混剪（网络新闻画面/历史纪录片空镜）
**脚本框架**：
1. 抛事实：盘点哪些地方改了（上海、山东、北京、江苏等）
2. 立反面观点：有人说“学历史不如学编程”
3. 反击输出：引用“忘记历史意味着背叛”，辅以近代史画面蒙太奇
4. 引导讨论：分数可以取消，但历史不能被清零。你支持吗？

## 选题3：家长群自报“纪委书记”，这波显摆翻车了
**形式**：解说 + 截图/文字聊天记录展示（全屏、无需露脸）
**脚本框架**：
1. 开场描述：老师在群里发通知，某家长一句“我是纪委书记”金句炸群
2. 反转：官方回应此次自报属实，但纪委不是“免罪金牌”
3. 情绪输出：这群里混的不是家长，是人设。论“权力装点门面”的荒诞
4. 结尾抛问：你家长群见过最牛的身份介绍是什么？

## 选题4：全网都在“升咖”，井柏然为什么突然口碑翻红？
**形式**：影视素材盘点 + 弹幕式吐槽配音（不露脸）
**脚本框架**：
1. 事件引入：井柏然“升咖”热搜，但他是靠作品还是靠综艺？
2. 片段集锦：罗列《早春晴朗》拍摄花絮+《花少》搞笑片段，配趣味解说
3. 内核分析：大家爱的不是他多帅，而是“有边界感的营业”+“有作品不包热搜”
4. 金句收尾：内娱最稳的咖，是“不声张，有回响”

## 选题5：花4.9元就能让手机壳“降级”变贵？最全手机壳智商税测评
**形式**：桌面俯拍 + 评测解说（只拍手/手机壳/游标卡尺，全程不露脸）
**脚本框架**：
1. 疑问开场：为什么有的手机壳卖3块，有的卖300块？
2. 实地测试：厚度/手感/镜头膜防护/氧化变黄对比（用小道具实拍）
3. 直给结论：贵壳不一定防摔，防摔看“气囊”不看价格
4. 实用建议：油皮不要买透明壳，游戏党必看散热
5. 收尾金句：便宜的壳摔碎了不心疼，贵的壳摔碎了才心疼。
