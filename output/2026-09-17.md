# TOP5 选题推荐

## 选题1：举手式睡姿是身体在求救
形式：科普解说 + 动画示意图/文字弹幕 + 实拍手部出镜（不露脸）
脚本框架：
1. 开头抛出悬念：你睡觉是不是喜欢把手举过头顶？别觉得可爱，这可能是身体在求救
2. 解释原理：举手睡姿=肩颈代偿，长期可能意味着颈椎/呼吸/压力问题
3. 列出自查清单：3个信号判断你是"舒服"还是"求救"
4. 给出改善方案：2个简单调整动作
5. 结尾互动：评论区告诉我你中了几条

## 选题2：小朋友什么行为显得没家教
形式：盘点解说 + 情景演绎（只拍手部/物品/背影）+ 文字卡片
脚本框架：
1. 开头：一个孩子有没有家教，吃一顿饭就能看出来
2. 盘点5种行为：乱翻菜、打断大人说话、公共场合尖叫、不打招呼、要东西不给就哭
3. 每种行为配一个简短情景画面（只拍桌面/手部/环境）
4. 给出家长应对建议
5. 结尾：家教不是打出来的，是带出来的

## 选题3：影视飓风Tim反掰iPhoneDuo被质疑

# 优选完整脚本

**选题：举手式睡姿是身体在求救**
**时长：60秒**

| 时间 | 画面 | 台词 |
|------|------|------|
| 0-3s | 黑底白字大字幕："举手睡觉=身体求救？" + 一只手举过头顶的剪影 | 你睡觉是不是也喜欢把手举过头顶？ |
| 3-8s | 动画示意图：人体肩颈肌肉群高亮，箭头标注"代偿" | 别觉得这个姿势可爱，它可能是你的肩颈在替身体求救。 |
| 8-18s | 分屏：左边"正常睡姿"骨骼图，右边"举手睡姿"骨骼图，红色标注受压区域 | 正常睡觉时，肩颈是放松的。但当你习惯性举手，说明肩颈肌肉一直在紧张代偿，它在帮你撑住不该撑的东西。 |
| 18-30s | 文字卡片逐条弹出：①颈椎曲度变直 ②呼吸模式异常 ③长期压力过大 | 如果你还伴随这三个信号——颈椎经常酸、睡觉用嘴呼吸、白天莫名疲惫——那就不只是睡姿问题了。 |
| 30-45s | 实拍手部出镜：演示两个拉伸动作（不露脸，只拍肩颈和手） | 教你两个动作自查：第一，靠墙站，后脑勺能不能贴到墙；第二，双手举过头顶，肩膀会不会立刻耸起来。 |
| 45-55s | 动画演示：侧睡抱枕、仰睡垫颈的正确姿势 | 改善方法很简单：侧睡时两腿之间夹个枕头，仰睡时脖子下面垫毛巾卷，让肩颈真正放松。 |
| 55-60s | 黑底白字："你中了几条？评论区告诉我" + 关注引导 | 你中了几条？评论区告诉我。关注我，每天一个身体冷知识。 |
