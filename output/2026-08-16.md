# TOP5 选题推荐

## 选题1：胖东来闭店，一个商业神话的“人味”告别
- **参考标题**：《胖东来关门，顾客却哭了：这TM才是中国商业该有的样子》
- **形式**：图文盘点+情感旁白解说（素材拼贴+空镜）
- **脚本框架**：
  1. 开场悬念：一家超市关门，为什么能上热搜第一？
  2. 素材展示：收银口排长龙、顾客抹泪、裁缝摊主哽咽的画面描述。
  3. 深挖细节：闭店原因（或主动调整/租金/经营策略），用B-roll替代人脸。
  4. 上升价值：从“超市”升华到“商业温度”，对比其他企业冷血关店。
  5. 结尾互动：你去过胖东来吗？评论区聊聊你的“意难平”。

## 选题2：从乐坛顶流到“汉奸”标签，石平的人生坠落记
- **参考标题**：《他曾在日本万人追捧，如今参拜靖国神社，评论区骂了10万条》
- **形式**：多平台网友反应截图轮播+历史资料配音解说（无出镜，用黑白影像）
- **脚本框架**：
  1. 开头抛事件：石平是谁？他做了什么事？
  2. 时间线回溯：早年风光、旅日经历、立场转变。
  3. 舆论切片：微博、知乎高赞评论滚动展示（素材以文字形式呈现）。
  4. 终极提问：背叛故土的人，最终能得到什么？
  5. 警示收尾：历史不容遗忘，底线不容试探。

## 选题3：王传君“原谅”了爱情公寓，但观众没原谅？
- **参考标题**：《当年的“关谷神奇”终于低头了！王传君这波是和解还是妥协？》
- **形式**：影视剧片段混剪+微博截图+解说配音
- **脚本框架**：
  1. 引子：热搜词条截图+《爱情公寓》经典BGM起。
  2. 争议回顾：王传君当年“不演关谷”的叛逆言论复盘。
  3. 事件反转：如今“和解”言论曝光，网友两极评论展示。
  4. 娱乐评论UP主式分析：是为了新戏宣传？还是人设崩塌？
  5. 抛出话题：你觉得他这是“真性情”还是“向钱低头”？
