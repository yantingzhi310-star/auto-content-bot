# TOP5 选题推荐

## 选题1：不要买会增加你工作量的东西
- **形式**：干货盘点（真人不出镜，拍实物/混剪购物场景）
- **脚本框架**：
  - 钩子：用一句扎心反问开场，直击"买时一时爽，用后火葬场"的痛点。
  - 盘点：列3-4个典型"增加工作量"的物品（如难打理的地毯、功能复杂的烤箱、需要手洗的衣物等），搭配痛点吐槽。
  - 反转/升华：消费主义陷阱剖析，教观众如何用"可维护成本"筛选物品。
  - 结尾：金句总结，引导评论区晒"最后悔买的东西"。

## 选题2：上海体育局被网友质问
- **形式**：新闻解说（使用新闻截图/纸媒画面+画外音）
- **脚本框架**：简述事件起因（具体质问内容），梳理网友观点和官方回应，延展到公职人员舆情应对的常识科普。
- **注意**：本选题为公共事件，需客观中立，事实引用需准确。

## 选题3：中国女生尸体被弃垃圾焚烧厂或被毁
- **形式**：深度解说（地图/资料画面+画外音）
- **脚本框架**：简述案件时间线，冷静陈述事件进程及最新进展，科普海外安全自救常识或医疗常识。
- **注意**：内容需严谨，引用官方通报，避免煽动情绪。

## 选题4：中元节传统禁忌
- **形式**：传统民俗科普解说（素材画面+画外音）
- **脚本框架**：用悬念开场说出1-2条冷门禁忌，引出中元节的文化起源，解读禁忌背后的社会心理和人文关怀，结尾用"但行好事"升华。

## 选题5：网友吐槽清华美院教授画的清洁工
- **形式**：混剪+吐槽点评（画面用画作截图，配音点评）
- **脚本框架**：直接展示相关画作，快速梳理网友争议焦点（画作与"清洁工"身份/形象的不符），提出开放性问题引发讨论。
- **注意**：对艺术创作本身持保留态度，避免人身攻击，聚焦"批评是否合理"的思辨。

# 优选完整脚本

**选题：** 不要买会增加你工作量的东西

| 时间 | 画面 | 台词 |
| :--- | :--- | :--- |
| 0-5s | 快速剪辑：花大价钱买的吸尘器吸头缠绕头发、满是水渍的玻璃茶几特写 | 你有没有发现，自从买了某样东西，你的生活质量不升反降？ |
| 5-15s | 画面切换：主播视角的手，正在翻看某电商App的购物车截图 | 花了钱，买回来的不是享受，是伺候它的工作量。今天咱们就盘一盘，那些“买时一时爽，用后火葬场”的玩意儿。 |
| 15-25s | 素材展示：昂贵地毯的清洗对比图；扫地机器人被电线卡住的搞笑混剪 | 第一类，是“美丽废物担当”。比如这种长毛地毯，踩上去是软，但你得配个专用吸尘器，还得定期请人深度清洁。你以为买的是格调，其实是给保洁阿姨买业绩。 |
| 25-35s | 画面切换：手举一台功能繁多的料理机，旁边放着吃灰的酸奶机、榨汁机 | 第二类，是“伪精致小家电”。买之前想象自己是美食博主，买之后发现，光是洗配件、拆零件的时间，都够点三顿外卖了。这种“增加工作量”的本质，是它太高估了你的勤劳。 |
| 35-45s | 混剪：刚买的真丝衬衫需要手洗的画面，和白色帆布鞋刷洗对比 | 第三类，是“伺候不起的娇贵单品”。为了好看，买需要特殊洗护的衣物。每次穿完都要手洗、阴干，不然就变形。这些东西就像个祖宗，是它们用你，不是你用它。 |
| 45-55s | 画面切回：手边拿着纸笔，在一个小本子上做笔记的画面 | 记住一个原则：买任何东西之前，先问自己一句——“未来的我，愿意为它多花多少‘维护时间’？” 如果答案是不愿意，那就别买。 |
| 55-60s | 黑底白字文案：把减少“维护成本”，当成新的购物标准。 | 能让人变懒的，才是真正的好东西。把钱花在“省事”上，永远比花在“找事”上划算。评论区聊聊，你买过最后悔的一样东西是什么？ |

- **贵不是问题，难伺候才是原罪。**
