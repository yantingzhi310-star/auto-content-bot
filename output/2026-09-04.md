# TOP5 选题推荐


## 选题1：男子欠债105万，靠学"胖东来"还清了？这操作绝了
**形式：** 配音解说 + 图文混剪（无真人出镜）
**脚本框架：**
- **钩子（0-3s）：** 抛出极端反差——欠债想轻生 vs 靠学超市经营还清105万，引发好奇。
- **铺垫（3-15s）：** 交代人物背景：普通打工人，欠债105万，走投无路。
- **转折（15-35s）：** 重点拆解他学了胖东来的什么？——极致的服务细节、真诚不套路、把顾客当家人（结合具体案例）。
- **高潮（35-50s）：** 他如何把这些理念用到自己的小生意中，从无人问津到顾客爆满。
- **升华（50-60s）：** 负债不可怕，真诚是唯一的必杀技。结尾引导评论“你学废了吗？”


## 选题2：毛阿敏对许晴称呼的变化，暴露了娱乐圈最现实的一面
**形式：** 影视素材混剪 + 解说配音（不露脸）
**脚本框架：**
- **钩子（0-5s）：** 直接点出“称呼变了，关系就变了”——毛阿敏从叫“晴儿”到叫“许晴”。
- **回顾（5-25s）：** 用过往综艺素材展示两人曾经亲密互动，称呼亲昵。
- **转折（25-45s）：** 分析综艺《花少》中两人关系微妙变化的瞬间，通过称呼、微表情、座位距离等细节印证。
- **解读（45-55s）：** 上升到人际关系的普遍规律：成年人的友谊，散场都是悄无声息的。
- **收尾（55-60s）：** 金句收尾，引发共鸣。

## 选题4：花少5是唯一获奖的一季？把许晴和毛阿敏的争议推上风口

- **铺垫（5-20s）：** 抛出数据结论，并引出花少2的“封神”级名场面（如“上一季的人都正常”）。
- **细节分析（20-45s）：** 重点解说毛阿敏、许晴、宁静之间的修罗场瞬间，分析人际关系中的暗流涌动。

- **结尾（55-60s）：** 戏称“花少2是综艺界的《甄嬛传》，建议列为人类学观察样本。”

# 优选完整脚本（选题1：男子欠债105万学胖东来）


**核心逻辑：** “学胖东来”只是一个壳，内里是认知反转——靠极度真诚、极致服务翻身。这个故事覆盖困境、方法、逆袭、感动四大情绪点，极易引发转发。

| 时间 | 画面 | 台词 |
| :--- | :--- | :--- |
| **0-5s** | 【大字标题冲击】黑底白字炸屏：“欠债105万，想自杀，最后他靠学‘胖东来’还清了？” 背景音效：沉重的鼓点 | 一个普通男人，欠了105万。他站在天台，想一了百了。但他没有跳。他转身去了趟许昌。 |
| **5-12s** | 快速剪辑：医院病房里男人绝望的脸、成堆的账单特写、烟灰缸里满满的烟头；转场：胖东来超市里人山人海的画面、员工微笑服务画面。 | 他叫老李，开小餐馆的，疫情三年赔光了积蓄，还欠了供应商105万。老婆孩子跟着他受苦，他想过死。但朋友跟他说：“你去看看胖东来，再决定死不迟。” |
| **12-25s** | 老李旁白（电话录音感）：“我在胖东来待了三天。我看到员工跪在地上擦地，不是因为地脏，是因为怕顾客滑倒。我看到顾客问路，员工不是指个方向，而是直接把人带过去。那时候我才明白，我不是输在市场不好，我是输在——我从来没把顾客当人看。” | 他去了许昌，在胖东来门口蹲了三天。他看到的不是超市，而是一堂关于“真诚”的课。 |
| **25-40s** | 画面配合动画图标逐条展示方法论：① 免费赠汤（成本5元）；② 不推销只推荐；③ 菜品有问题无条件重做；④ 记住老顾客口味与姓名。背景音乐转为激昂燃向。 | 回到自己的小餐馆，他开始“不要脸”地学：第一，每桌免费送一碗例汤，成本不到5块钱。第二，他要求服务员不准推销贵的菜，只推荐最合适的。第三，菜有问题，无条件重做，绝不废话。第四，他搞了个小本子，记录每个熟客的口味和忌口。 |
| **40-50s** | 画面切换为手机聊天记录截图（好评刷屏）+ 餐馆门口排长队的实拍 + 老李在店里忙碌的背影。 | 第一个月，生意没好多少。第二个月，老顾客开始带新顾客来。到了第六个月，门口开始排队了。有顾客在点评软件上写——“这家店，吃的不只是饭，是尊重。” |
| **50-60s** | 画面定格在黑白海报风字幕上，居中大字号打出金句。背景音乐渐弱，保留一个水滴音效，然后收尾。 | 105万，他用了整整两年还清了。他说，胖东来救他的不是那套经营方法，而是一句话——**把良心摆在前头，钱就会跟在后头。** |
