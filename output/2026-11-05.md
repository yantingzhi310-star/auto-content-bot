# TOP5 选题推荐

## 选题1：用筋膜枪打肚子"减赘肉"，女子查出卵巢癌
形式：解说 + 新闻画面/示意图 + 大字幕
脚本框架：
1. 钩子：筋膜枪打肚子，本想减赘肉，结果查出卵巢癌
2. 还原：她怎么做的、身体出现什么信号、就医经过（据公开报道梳理）
3. 科普点：腹部包块别乱"震"、卵巢癌早期信号容易被当"胖/胀气"
4. 提醒：减肥工具≠医疗手段，异常腹胀、月经紊乱、体重变化要就医
5. 收尾互动：你身边有人拿筋膜枪乱打吗？

## 选题2：38岁男子被骗到缅甸，因"太老卖不掉"
形式：解说 + 地图/流程示意 + 字幕节奏卡点
脚本框架：
1. 钩子：被骗到缅甸，居然因为"太老"没被卖掉
2. 诈骗链条拆解：招聘话术→出境→"验货"→转卖失败
3. 反常识点：年龄、体检、话术如何筛选受害者
4. 防骗清单：境外高薪、包机票、先交钱、催你立刻走
5. 收尾：把这条转给家里找工作的人

## 选题3：女厕偷拍者有女性甚至夫妻

5. 收尾：把"检查动线"做成3步口诀

# 可做封面的金句
- 筋膜枪打肚子减赘肉，打出的是"卵巢癌"三个字
- 腹部不是脂肪块，别拿它当"震动减肥区"
- 持续腹胀两周，先查，别先减
- 减肥工具，永远替代不了体检
- 被骗到缅甸因"太老卖不掉"：骗子也在挑人
- 偷拍者不一定是"你想的那种人"，进门先看这三处
- 52分24板8帽：这不是游戏数据
- "发大财的行业"里，最难的是门槛不是风口
