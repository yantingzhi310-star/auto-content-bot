# TOP5 选题推荐

## 选题1：原来百家讲坛是真的在教东西
形式：解说 + 历史画面/古装剧混剪
脚本框架：
1. 钩子：小时候当催眠节目，长大才发现全是人生干货
2. 举例3个百家讲坛名场面（王立群讲项羽、易中天讲曹操、于丹讲论语）
3. 每段提炼一句"放到今天职场/人际同样适用"的话
4. 结尾：建议年轻人当下饭剧重刷

## 选题2：上1休1上5休3
形式：配音画面 + 日历动画/白板手写
脚本框架：
1. 抛出2026年某月真实排班日历，念出"上1休1上5休3"
2. 算一笔账：这个月实际只上X天班
3. 对比常规双休，多出多少天假
4. 提醒：调休本质是"借假"，你真正赚了吗？
5. 结尾互动：你愿意用这种排班换吗？

## 选题3：每个中国人都不能忘记九一八
形式：纪录片画面/黑白影像 + 旁白解说
脚本框架：
1. 开头：防空警报声 + 日期字幕"1931.9.18"
2. 3个关键数字（时间、地点、后果）
3. 一段简短但有力的历史陈述，不煽情但克制
4. 结尾：今天的警报你听到了吗

## 选题4：月薪4万就是每天都有1333
形式：配音画面 + 计算器/数字动画
脚本框架：
1. 开头：把月薪拆成日薪，数字一出来人就清醒了
2. 算账：4万÷30=1333，再算时薪、每分钟
3. 对比：你每天摸鱼2小时=扔掉266元
4. 反转：但月薪4万的人根本没时间算这个
5. 结尾：算完你是更有动力还是更焦虑？

## 选题5：机顶盒即将退场
形式：盘点解说 + 老物件画面/怀旧素材
脚本框架：
1. 开头：你家那个吃灰的机顶盒，要正式退役了
2. 回顾：从有线电视到机顶盒到智能电视的20年
3. 为什么退场：内容内置化、投屏普及
4. 怀旧点：多少个暑假是守着机顶盒换台度过的
5. 结尾：你家机顶盒现在还在用吗？
