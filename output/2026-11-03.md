# TOP5 选题推荐

## 选题1：赴港看演唱会女孩低保被取消
形式：横屏解说 + 新闻截图/文字板轮播（不露脸纯旁白）
脚本框架：
1. 钩子（0-3s）："为了看一场演唱会，她丢了低保——值吗？"
2. 事件还原（3-20s）：女孩赴港看演唱会→低保资格被核查取消，时间线用文字板呈现
3. 争议点拆解（20-40s）：程序合规 vs 情理之争，评论区两种声音对撞
4. 升华提问（40-55s）：低保的本质是什么？个人消费自由的边界在哪？
5. 互动引导（55-60s）："你怎么看？评论区见"

2. 事实梳理（3-20s）：情侣被打伤情+目击者回应，时间线还原
3. 三方视角（20-40s）：年轻人/老年人/景区管理各自的问题点
4. 深层追问（40-55s）：旅游冲突频发，是素质问题还是规则缺位？
