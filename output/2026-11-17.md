# TOP5 选题推荐

## 选题1：信小呆的1亿奖品，8年后变成了什么？
形式：解说+资料画面（旧新闻截图/文字卡片/时间轴动画）
脚本框架：
1. 钩子：2018年那个"中国锦鲤"，现在怎么样了？（0-3s）
2. 反转：她自曝环游世界后"落后了太多"——1亿奖品是馅饼还是陷阱？（3-15s）
3. 拆解：200多家商家奖品≠现金，兑奖成本、时间成本、机会成本逐条算账（15-40s）
4. 升华：免费的东西最贵，运气红利也有保质期（40-55s）
5. 互动钩子：如果是你，接不接这1亿？（55-60s）

## 选题2：于东来又发车了：310辆坦克700，胖东来式分钱逻辑
形式：解说+新闻截图+数据卡片动画
脚本框架：
1. 钩子：别人年终奖发红包，这家公司直接发310辆越野车（0-4s）
2. 事实：奖励对象、总价值估算、这不是第一次（4-20s）
3. 拆解：为什么胖东来/于东来总能上热搜？"分钱哲学"三个关键点（20-45s）
4. 对照：普通打工人看完的真实感受（45-55s）
5. 互动：你老板上次奖励你什么？（55-60s）

## 选题3：每天吃饭用秤量，妻子崩溃——极端自律还是心理问题？
形式：配音画面+情景动画/文字演绎
脚本框架：
1. 钩子：36岁男子顿顿吃饭上秤，精确到克，妻子崩溃了（0-4s）
2. 还原：他到底怎么吃、为什么吃、家里什么状态（4-20s）
3. 两派观点：健康管理派 vs 控制欲/焦虑派（20-40s）
4. 专业视角：什么程度的"自律"已经越界（40-52s）
5. 互动：你能接受伴侣这样吗？（52-60s）

## 选题4：甄嬛传播放量最高的不是滴血验亲，那到底是哪集？
形式：盘点+剧集截图/名场面剪辑（纯画面+解说，不露脸）
脚本框架：
1. 钩子：所有人猜滴血验亲，数据打脸（0-4s）
2. 揭晓：播放量最高集数+原因分析（4-15s）
3. 盘点：第2-5名名场面，每集一句话点评（15-45s）
4. 观点：为什么这集能封神——情绪密度最高（45-55s）
5. 互动：你心中的第一名是哪集？（55-60s）

## 选题5：王自如谈字节"只差一个聊天软件"——这话对吗？
形式：解说+文字卡片+对比图（微信 vs 抖音生态）
脚本框架：
1. 钩子：王自如一句话上热搜：字节只差一个聊天软件（0-4s）
2. 拆解：字节做过的社交尝试（多闪/飞聊等）为什么没成（4-25s）
3. 反方：不是"差一个软件"，是差一张关系网（25-45s）
4. 观点：社交的护城河是习惯，不是功能（45-55s）
5. 互动：如果字节出聊天软件，你会用吗？（55-60s）
