# TOP5 选题推荐

## 选题1：国家癌症中心公布发病前五癌症 + 甲状腺癌为何越来越多（合并）
形式：数据解说 + 信息图动画（纯录屏/字幕卡）
脚本框架：
1. 开场钩子：一张图看懂中国人最容易得的5种癌
2. 逐一过前五癌症，每条配一个"最容易忽略的信号"
3. 单独展开甲状腺癌：为什么体检一查一个准（过度筛查vs真实增长）
4. 结尾：3条可执行的筛查建议，引导收藏

## 选题2：拟出台的中国AI禁令震动全球 + 诺奖得主忠告要聪明使用AI（合并）
形式：新闻解说 + AI生成画面/示意图
脚本框架：
1. 钩子：一条禁令，为什么让全球科技圈睡不着
2. 禁令核心3条，用大白话翻译
3. 诺奖得主那句忠告，到底在提醒什么
4. 普通人视角：这件事跟你有什么关系（工作/工具/孩子教育）
5. 结尾开放式提问引评论

## 选题3：目前我国只批准两款L3车型
形式：盘点解说 + 车型参数对比字幕卡
脚本框架：
1. 钩子：L3自动驾驶，全国只有两款车合法上路
2. 什么是L3，和L2差在哪（一个类比讲清责任转移）
3. 两款车分别是谁，凭什么拿到
4. 想买智驾车的人现在该等还是该买
5. 结尾：评论区问"你敢把方向盘交给车吗"

## 选题4：宝马员工争着离职挤崩系统
形式：职场解说 + 新闻截图/文字卡
脚本框架：
1. 钩子：一家公司员工抢着离职，把系统挤崩了
2. 事件还原：发生了什么，为什么集体走
3. 三个可能原因拆解（赔偿/转型/行业风向）
4. 普通人能学到的职场信号：什么情况下"走"是对的
5. 结尾：留问题"如果是你，走还是留"

## 选题5：男子捡到38000元留了道题给失主
形式：故事配音 + 情景画面（AI图/素材混剪）

2. 讲过程：题是什么，失主怎么答对的
3. 反转点：为什么用"考试"代替直接归还
4. 落点：善良+聪明的组合，比单纯好人更稀缺
5. 结尾：如果是你捡到，你会出什么题

# 优选完整脚本

选题：**男子捡到38000元留了道题给失主**
理由：故事性强、有反转、零门槛不露脸、天然带互动提问，完播和评论双高。

| 时间 | 画面 | 台词 |
|---|---|---|
| 0-3s | 黑底大字："捡到38000元，他没报警" | 捡到三万八，他没报警，反而给失主出了一道题。 |
| 3-8s | 手绘/素材：一沓现金放在桌上 | 事情是这样的，一位大哥捡到一个包，打开一看，三万八千块现金。 |
| 8-15s | 字幕卡："换你会怎么做？" | 换一般人，要么原地等，要么直接交派出所。但他没有。 |
| 15-25s | 微信聊天界面示意动画 | 他在包里找到联系方式，加上了失主，只说了一句：钱在我这，但你得先答对一道题。 |
| 25-35s | 字幕逐条弹出问题 | 题不难——包里除了钱，还有什么？少一样东西，说得越细，越能证明这包是你的。 |
| 35-45s | 打勾动画 / 对比画面 | 失主一条条答：身份证、银行卡、一张孩子的照片。全对。大哥这才把钱还了回去。 |
| 45-53s | 黑底白字金句 | 你看，他不是不信任人，他是用一道题，把"冒领"挡在了门外。善良，还带着脑子。 |
| 53-60s | 提问字幕卡 | 如果是你捡到这三万八，你会出什么题？评论区见。 |
